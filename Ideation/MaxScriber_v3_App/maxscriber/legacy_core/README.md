# Legacy Core Module

This module houses the multi-pass regex brute-force logic inherited from `Max_Scriber_Tool_2_Repo_Final`. 
It serves as the foundation for the Phase 1 implementation of MaxScriber v3, maintaining backwards compatibility 
with the existing text-based extraction engine before we transition to the AI-driven LayoutLMv3 models.

The code placed here is designed to be fully decoupled and interface smoothly with the new SQLite-based format registry.
